AlarmLens ↗

  • Python
  • pandas
  • ISA-18.2
  • Ollama

An alarm-management analyzer for SCADA alarm logs. It reads a CSV export and measures the alarm system against ISA-18.2 / EEMUA 191 style benchmarks. The one-page report shows bad actors, chattering and stale alarms, flood episodes and the priority mix, with prioritized rationalization actions. An optional summary comes from an offline AI model, so no plant data leaves the PC.

8 alarm KPIsAlarms per day and per 10 min, time in flood, top-10 share, more
Finds bad actorsChattering, stale and flood-causing tags
Operator responseTime to acknowledge, and the alarms operators ignore
Drop and analyzeDrag in any SCADA CSV export; columns are auto-detected

Rules-Based Trading Desk

  • Python
  • Backtesting
  • AI agent
  • Brokerage API

A personal trading system run like a control system. Every strategy is tested on historical prices before it's allowed to run, a scheduled AI agent follows fixed rules each market day, and hard interlocks stop it from doing anything outside those rules. Every trade is logged to a journal.

Evidence firstPython backtests of about a dozen strategies on about 2 years of daily data
Hard interlocksPosition, order and sector limits, an earnings blackout, and a review check before every order
Automated daily runReads state, applies the rules, logs each trade and sends a plain-language summary
Fail safeAnything unclear or unexpected means no order, and it gets reported
